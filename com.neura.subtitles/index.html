Connecting to Premiere…

1. Paste subtitles

Blank line → new subtitle. [Words] → highlighted range inside the same text layer. All text is set in lower case; Default and UGC highlights get Premiere's All Caps button. Every highlight uses the Italic face from Premiere's Font Style list. Text is centred. Without (0:03–0:06) timings, Create times every block from the chosen voice track automatically.

Timing options

Audio timing

Recognises the original media files (mp4, mov, wav…) of the clips on the chosen track — only the parts used in the edit — and maps every word to the timeline. Music on other tracks does not interfere. Create does this automatically for blocks without timings; this button is an optional preview you can edit. Each block is trimmed to its spoken words, short pauses are closed so subtitles do not flicker, and a block that is not heard clearly is placed between its neighbours and listed. First use: run Install_Audio_Timing.cmd from the ZIP.

Restyle timeline selection

Select subtitle clips, or their Neura overlay to change the entire nested sequence (all instances). A click saves your current edits and opens a styled project copy beside the original.

Edit in Premiere

Double-click the subtitle overlay or click Open text clips. Select a graphic, press T, and edit the single text layer in the Program Monitor. Use Properties for styling. Trim individual clips for timing.

Regular and highlighted parts are formatting ranges in one text object. Text is lower case; Default and UGC highlights use Premiere's All Caps button. Leading is −5, highlights use the Italic font style, always at size 80.

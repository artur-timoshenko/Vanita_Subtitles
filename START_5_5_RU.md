# Neura Subtitles 5.5 · Windows

Закрой Premiere и запусти Install_Windows.cmd из распакованного ZIP. Для автотаймингов по речи один раз запусти Install_Audio_Timing.cmd. Нужны Python 3.11 (64-bit), доступ к PyPI и Hugging Face, место для модели и пакетов. Распознавание идёт локально, аудио в облако не отправляется.

## Что нового в 5.5

- Текст выровнен по центру. Позиция: «Screen center» (по умолчанию) или «Bottom (−300 px)».
- Новый стиль Reaction: как Default, но выделенные слова отличаются только цветом #F4D178 (без Italic и All Caps).
- В одной строке не больше 3 слов: 4-е и следующие автоматически переносятся на новую строку.
- Весь текст пишется маленькими буквами (никаких «Привет ОЛЕГ»). Выделенные [слова] в Default и UGC получают кнопку Premiere All Caps (сами буквы остаются маленькими). Во всех стилях, кроме Reaction, выделение — это начертание Italic из списка Font Style, а не функция Faux Italic. Leading −5.
- Автотайминг: вставь блоки без таймингов и нажми Create & add subtitles. Каждый блок обрезается по своим словам в аудио, паузы короче 0,6 с закрываются (без мигания). Если блок не расслышан, он ставится между соседями и перечисляется в статусе, а не роняет всю операцию.

## Работа

Открой смонтированную секвенцию и в разделе Audio timing выбери **Voice track** — дорожку с голосом (например, A1). Плагин берёт исходные файлы клипов на этой дорожке (mp4, mov, wav…), распознаёт только использованные в монтаже куски и переносит каждое слово на таймлайн. Музыка на других дорожках не мешает, экспорт и WAV-пресет не нужны.

Вставь блоки текста в порядке речи: пустая строка — новый субтитр, один перенос — новая строка внутри того же блока. [Скобки] отмечают акценты. Нажми Create & add subtitles. Чтобы проверить тайминги до создания клипов, нажми Detect timing from voice track: результат появится в текстовом поле, где его можно поправить. Уже размеченный текст (0:03–0:06) не перерассчитывается.

На голосовой дорожке должны быть обычные клипы из файлов: вложенные секвенции и перевёрнутые клипы не анализируются, а офлайн-медиа плагин назовёт по имени. При нескольких дублях одинаковой фразы проверяй, какой дубль выбран.
